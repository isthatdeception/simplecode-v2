Also, just for your info

By default, browser tries to align the inner content that's text inside the button to the center of the button. But, if you add padding to the button, it will not be centered anymore. The text will be aligned to the left side of the button. This is because the default value of the box-sizing property is content-box. If you set it to border-box, then the text will be centered again.
